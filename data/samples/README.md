# Synthetic sample datasets

Every file here is **synthetic**: generated by `scripts/generate_samples.py` with a fixed seed. Nothing is
derived from real customers or real Freedom data. Regenerate them with `pnpm samples`.

| File | Shape it exercises |
| --- | --- |
| `customers_churn.csv` | Binary classification (`churned`), an identifier column, dates, booleans, missing values |
| `credit_limits.csv` | Regression (`approved_limit_kzt`), semicolon delimiter |
| `transactions.csv` | Daily time series with weekly seasonality and growth |
| `accounts_messy.xlsx` | Data quality: spelling variants, duplicates, numbers and dates stored as text (two sheets) |
| `branches.parquet` | Parquet import; operational data with no target (analysis without ML) |

`catalog.json` describes them for the "Load sample" panel. Real case data received on the day belongs in
`data/workspaces/` (through the upload UI) or `data/private/`. Both are git-ignored.
